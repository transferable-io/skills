# Transferable skills

Agent skills for [Transferable](https://transferable.io).

```sh
npx skills add transferable-io/skills
```

With the [Transferable CLI](https://github.com/transferable-io/cli) installed (0.2.2 or
later), `transferable skill install` does the same for the coding agents of the computer,
and `transferable update` keeps the skill current.

- `transferable`: upload files and send deliveries with the
  [Transferable CLI](https://github.com/transferable-io/cli).
